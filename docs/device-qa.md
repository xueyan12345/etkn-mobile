# 真机验收清单

CI 只证明“能编译、单测与 Lint 通过、签名正确”。以下项目需在真机上逐项确认，结果写回 `.agent/CONTINUITY.md`。

## 连接与账号
- [ ] 局域网 HTTP 地址（如 `192.168.x.x:8097`）与 HTTPS 反代地址均能识别为 ETKN；普通 Emby/Jellyfin 地址被拒绝。
- [ ] 填管理端口（5257）时自动切到媒体地址，并校验实例身份。
- [ ] 普通账号重启 App 后免登录；管理员仅在服务端“保存管理员账号”开启时免登录；私密账号不留记录。
- [ ] 切换账号 / 退出后，首页、音乐队列与图片缓存不串号。

## 浏览
- [ ] 搜索页进入即弹出输入法，点击输入框可正常输入；顶部玻璃输入框随结果滚动呈毛玻璃。
- [ ] 媒体库列表与库内海报墙可上下滚动并自动加载下一页；顶部玻璃栏内排序/收藏筛选在结果为空时仍可操作。
- [ ] 首页顶栏始终为毛玻璃（海报上为暗色玻璃+白字，滚动后为表面玻璃）；下拉刷新与上滑时 Hero 背景不越出边界、无错位。
- [ ] 首页 Hero 首条推荐快速出现并自动轮播；继续观看进度条、长按移除确认。
- [ ] 海报墙滚动 60fps 无明显掉帧（GPU 呈现模式或 `adb shell dumpsys gfxinfo`）；排序与收藏筛选正确。
- [ ] 详情：剧照/Logo、技术参数、多版本、季切换与分集分页（>60 集的季）、演职员、相似推荐。
- [ ] 浅色 / 深色 / 跟随服务器主题色 / 壁纸取色 / 纯黑模式；平板横屏为侧边导航。

## 影视探索
- [ ] 有探索权限的账号出现「探索」（手机底栏、平板侧栏），无权限账号不出现；电影/剧集切换、搜索、筛选（排序/类型/年代/评分/隐藏已入库）与无限滚动正确。
- [ ] 详情：背景、简介、季度、演员 → 人物参演作品；订阅影片/单季/全部缺失季后状态变为“待订阅”；已入库项可跳转片库观看。
- [ ] 云资源：三源并行搜索、各自显示数量或失败；共享池剧集按季分组；获取前弹确认，提交后显示任务号与“已提交”标记。

## 更新与布局
- [ ] 自动检查开启时启动弹出新版本面板；加速源/直连可切换，下载显示进度与速度，取消或失败后下载目录无残留文件；校验通过后可调起安装（首次引导开启“安装未知应用”）。
- [ ] 平板（≥600dp）与横屏：侧栏导航、首页横幅 Hero、设置居中、网格列数合理。
- [ ] 预测性返回：拖动时当前页成为带圆角的不透明卡片随手指缩小，下层页面完整可见、无内容穿透或错位。
- [ ] 外观 → 页面大小：小/标准/大/特大切换后整页（含对话框、底部面板、下拉菜单、播放器）一起缩放；手机在“特大”下仍为底栏布局。
- [ ] 外观 → 首页推荐：自动轮播 / 手动切换（不自动翻页）/ 隐藏（顶栏直接为玻璃横条）。
- [ ] 底栏选中项色块同时包住图标与文字，切换时色块滑动。
- [ ] 外观 → 底栏：勾选/取消页面后底栏即时变化，首页不可取消，手机最多 5 项；平板 → 导航位置：侧边/底部切换正确，迷你播放器位置随之变化。
- [ ] 长按海报 / 继续观看卡片：毛玻璃菜单从卡片处弹出，背景模糊；普通账号只有收藏/标记，管理员有刷新/编辑元数据/编辑图片/提取缩略图/删除，继续观看卡片多“从继续观看移除”；详情页“更多”按钮同菜单。
- [ ] 刷新：两个开关至少开一个；提交后顶部提示，任务完成后提示“已刷新”并更新海报。编辑元数据保存后列表/详情更新；编辑图片可切换海报/背景/标志与全部语言，点选或上传后生效。
- [ ] 删除：多版本可选单个版本或全部；删除当前详情后自动返回，列表中该项消失。（请用测试媒体验证，删除会进入联动删除流程。）
- [ ] 对话框、底部面板（筛选、更新、编辑）在 Android 12+ 背后为毛玻璃；人物/音乐列表/设置/账号页标题栏为悬浮毛玻璃，内容从下方滚过。
- [ ] 详情页元数据行显示完整上映日期与本集/本片时长（取不到时该段不显示，不出现 0 或编造值）。
- [ ] 剧集详情页 / 电影详情页 / 单集页：播放按钮**上方**常驻三条（视频 / 音频 / 字幕）；季详情页**没有**这三条。
- [ ] 三条里有多条选项时右侧有箭头、点开就地展开、选中项带勾；单音轨 / 无字幕时没有箭头。
- [ ] 音轨名不出现「(默认) (默认)」重复。
- [ ] 右上角对号点击 → 图标立刻变化、服务端状态同步、列表页角标跟着变；再点一次取消。
- [ ] 单集页「集号 + 集名」在播放按钮下方、简介上方，不在剧名下方。
- [ ] 单集页点「影片信息」：右侧浮出设置面板，含视频信息（分辨率/编码/大小/码率）、音轨（带「(默认)」标记）、字幕；多版本 / 多音轨 / 多字幕均可展开选择，选中项带勾选。
- [ ] 剧集详情页有「季」横排卡片区（海报 + 右上角集数 + 右下角评分 + 季名），选中季有描边；点季卡进入季详情页。
- [ ] 季详情页：顶部头图 + 剧名 + 季名 + 播放按钮 + 竖向剧集列表（左 16:9 缩略图，右为集号集名 / 时长 / 简介）。
- [ ] 章节缩略图在本集无章节图时，统一使用该剧的系列封面（同一集内所有章节卡为同一张图），不再出现「一张本集特写 + 其余别的场景」。
- [ ] 剧集横条点后面的集：整条平滑左移一张卡宽（目标集停在左起第 2 格）；点前面的集反向移动。
- [ ] 探索页往下翻后点进详情再返回：停在原滚动位置，不回顶部。
- [ ] 搜索库内没有的片名（有探索权限）：出现“探索 · 电影 / 剧集”两行结果，点开进入探索详情；无权限时仍显示“没有找到相关影视”。

## 视频播放
- [ ] H.264 / HEVC / HDR10 / 杜比视界直链硬解；TrueHD / DTS 音轨可出声（FFmpeg 兜底）。
- [ ] 外挂 SRT / ASS 字幕、内封字幕切换与关闭；普通字幕为白字描边、无黑色底框；音轨名称与服务端一致。
- [ ] 手势：双击 ±10 s、横滑定位、左亮度右音量、长按 2 倍速、锁定。
- [ ] 续播位置、跳过片头（按钮 / 自动）、片尾“下一集”、自动下一集。
- [ ] 选集/音轨/字幕/倍速/版本/弹幕面板从右侧滑入，左侧画面可见；Android 12+ 面板背后视频呈毛玻璃；面板打开时状态栏不出现。
- [ ] **长剧（1000+ 集）**打开选集：直接定位到当前集，且当前集上方和下方各能看到若干集（不是停在第一条）。
- [ ] **OPPO 平板**长选集列表：用力上滑有惯性，能快速滚过很多集（不是只能一格格扒）；手机端同样顺畅。
- [ ] 单集页点其他集：集标题/时长/简介正确切换，**选集分页区间跟着当前集走**（417 集点 419 仍停在 401-420，不跳到 61-80）。
- [ ] 连播几集后退出：每一集都在服务端留下各自的进度记录，不是全部停在最早那一集。
- [ ] 画中画进入 / 恢复 / 关闭；退出后服务端进度与“继续观看”更新（含 PlayedToCompletion）。
- [ ] 打开播放器的第一帧就是横屏（所有机型）；竖屏视频拿到真实尺寸后自动转回竖屏，不出现「先竖后横」。
- [ ] 缓冲条随播放位置连续前进（不是每几秒蹦一大截）；单集内缓冲条长度恒定；两个阈值任一达成就停止往后扩。
- [ ] 从中间开始播：缓冲推进到片尾即视为当前集完成（不要求前面 0 秒起全部缓存）。
- [ ] 当前集缓冲到片尾后，下一集自动开始预加载；`下一集` 按钮上的小气泡在下一集已可秒播时亮起；点下一集无延迟。
- [ ] 下一集有片头数据时，即使超出缓存配额也要缓冲到「片头结束 + 1 分钟」。
- [ ] 锁定后解锁按钮 3 秒自动淡出；锁定状态下点屏幕可再次唤出 3 秒；解锁后控制条恢复。
- [ ] 播放界面元素尺寸：时间/网速/电量/加载圈/拖动预览/手势反馈为原始大小；剧名艺术字与进度条整体高度为 1.5 倍；其余按钮图标与文字为 1.25 倍；跳过片头胶囊与「取消」保持原始大小。

## 平板专项（OPPO Pad Mini / OPD2515）

- [ ] 进播放器立刻是横屏画面（系统不认方向，靠画布旋转兜底），无「先竖后横」。
- [ ] 横屏下画面左右无黑边、不被裁切；视频居中。
- [ ] 点音轨 / 字幕 / 选集 / 弹幕 / 倍速：只弹出一个面板（不是两个）。
- [ ] 面板方向与画面一致（横向），贴在屏幕右侧，不贴边、不被上下边缘裁切，内容完整可滚。
- [ ] 点面板以外任意位置可关闭；点面板本体不会误关；系统返回键也能关。
- [ ] 手机与普通平板不触发画布旋转（画面与方向行为与之前完全一致）。

## 蓝光原盘
- [ ] 「我的 → 导出日志」可按日期与小时段导出，内容以错误与 ETKN 关键行为主，不含令牌与 URL 查询串；「清空」后再导出为空；闪退后重启仍能导出崩溃前的错误；7 天前的日志自动删除。
- [ ] 首页头像、媒体库排序、歌曲「更多」弹出的是与长按菜单一致的毛玻璃菜单，返回键与点空白处可关闭。
- [ ] 首页轮播图可手指左右滑动翻页。
- [ ] 首页各横向模块（媒体库 / 继续观看 / 最新）左右滑动顺畅，不出现「划不动、多划几次才行」。
- [ ] 主界面左右滑动不会切换底部标签（标签只由 Dock 驱动）。
- [ ] 切换账号后轮播图立刻换成该账号的推荐；切回旧账号时显示的是该账号上次刷新那一批（未满 12 小时沿用，满了立刻重抽）。
- [ ] 原盘从选片到出画面的等待明显缩短（元数据读取复用连接）。
- [ ] 全盘 ISO（含 UHD、杜比视界 profile 7）可起播、拖动、切换音轨（TrueHD/DTS-HD/LPCM）与 PGS 字幕；杜比视界原盘以 HDR10 播放。服务器本地 ISO 与 115 STRM ISO 各测一次。
- [ ] 加密原盘提示“仍受加密保护”；存储不支持 Range 时提示对应错误，不崩溃。
- [ ] 播放器右侧面板文字为浅色、背景与长按菜单同样的毛玻璃，左侧画面基本不被压暗。

## 弹幕
- [ ] 服务端开启弹幕服务时播放器出现“弹幕”入口；打开后提示“正在拉取弹幕…”→“弹幕已加载 / 未匹配 / 暂无”。
- [ ] 弹幕随播放滚动、暂停即停、拖动进度后重新排布；跨 2 分钟窗口无中断；行数/密度/字号/不透明度/速度/主题色即时生效。
- [ ] 服务端关闭弹幕时打开开关提示“请在服务端增强功能中启用弹幕服务”；画中画中不显示弹幕。

## 音乐
- [ ] 专辑 / 歌手 / 歌曲 / 文件夹 / 歌单浏览与分页；播放全部、随机、循环。
- [ ] 锁屏与通知栏控制、蓝牙按键、拔耳机暂停；后台播放不中断。
- [ ] LRC 同步歌词高亮与点击跳转；无歌词时在线补取。
- [ ] 歌单新建 / 删除 / 添加歌曲；“最近听的”在服务端更新。
